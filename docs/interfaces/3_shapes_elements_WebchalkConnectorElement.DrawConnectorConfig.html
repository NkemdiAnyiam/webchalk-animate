    autoRedrawEnabled

    autoRedrawEnabled: boolean

    If true, the endpoints of the connector will continuously update to match any positional changes in the target elements.

    Remarks

    If domLocation is used to insert the connector close to the target endpoints and neither endpoints will undergo transformations, specifying false is appropriate for optimization since the target elements will not be moving with respect to the connector.

    Default Value

    true
