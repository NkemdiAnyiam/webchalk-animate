ERROR: Invalid Entrance Attempt

Entrance()
can only play on elements that are already hidden, but this element was not hidden. To hide an element, you can do one of the following:
  • Use the 
    {hideNowType}
    config option to immediately hide the element from the very start.
    Example: 
    
                    const sequence = webchalk.newSequence([
                      Entrance(elem, '~fly-in', ['from-left'], {hideNowType: 'display-none'}),
                    ]);
  • Hide the element with 
    Exit()
    before the 
    Entrance()
    animation runs.
    Example: 
    
                  const sequence = webchalk.newSequence([
                    Exit(elem, '~fade-out', []),
                    Entrance(elem, '~fly-in', ['from-left']),
                  ]);
  • Manually add either 
    "webchalk-display-none"
    or 
    "webchalk-visibility-hidden"
    to its CSS class list in the HTML.
    Example: 
    
                  <div class="some-class another-class webchalk-display-none">...</div>
**********

Tip
  • Adding 
    "webchalk-display-none"
    to an element's CSS class list applies a 
    {display: none;}
    CSS style, which completely unrenders an element.
  • Adding 
    "webchalk-visibility-hidden"
    applies a 
    {visibility: hidden;}
    CSS style, which just makes the element invisible while still taking up space.
  • When using 
    {exitType}
    with 
    Exit()
    or 
    {hideNowType}
    with 
    Entrance()
    , you may set the config options to 
    "display-none"
    (the default for 
    {exitType}
    ) or 
    "visibility-hidden"
    , but behind the scenes, this just determines whether to add the class 
    "webchalk-display-none"
    or the class 
    "webchalk-visibility-hidden"
    .
